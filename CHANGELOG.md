# Changelog

All notable changes to Modulo are documented in this file.

Entries are generated automatically from merged pull requests, classified by
their `changelog:*` labels (see `scripts/generate_changelog.py`, run by the
`release` action in `.github/workflows/release.yml`):

| Label | Section |
| --- | --- |
| `changelog: breaking` | **Breaking Changes** |
| `changelog: feature` | **Features** |
| `changelog: fix` | **Fixes** |
| `changelog: none` | excluded (no entry) |

Pull requests without a `changelog:*` label are never listed individually;
they are only counted in a single trailing "Other" line.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)
and this project adheres to
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).
