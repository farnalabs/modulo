# Community Library

The Modulo Community Library is a registry of shareable primitives including
schemas, agents, workflows, and integrations. Users can browse existing
primitives, copy them to adapt, rate them, and contribute their own test
fixtures.

## Contribute Fixtures

Users can create test fixture contributions that go through a review workflow:
draft → review queue → published. See the [PRD §8.14](/docs/prd.md#814-community-library)
for detailed specifications.

## Browse and Search

Library primitives can be browsed by type, searched by name or description,
and filtered by source (local or community).

## Ratings

Community primitives can be rated thumbs up/down. Ratings require at least
one prior copy-to-adapt of the primitive.
