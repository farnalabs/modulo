# Variant Execution (A/B Testing)

Variant execution extends pipelines with A/B testing capabilities, allowing
weighted random selection of pipeline variants, quota enforcement, and
coverage gap detection. See the [PRD §8.19](/docs/prd.md#819-variant-execution)
for detailed specifications.
