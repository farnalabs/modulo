# SSO Team Mapping

Configure group-to-team mappings from OIDC/SAML identity provider group claims to Modulo team memberships. Applied at JIT user provisioning time.

See the [PRD §9.4](https://github.com/farnalabs/modulo/blob/main/docs/prd.md#94-authentication) for full details.
