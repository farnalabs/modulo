# OIDC Integration

OpenID Connect Single Sign-On with authorization code flow, discovery document parsing, JIT user provisioning, and group-to-team mapping.

See [PRD §9.4](../../docs/prd.md#94-sso-and-identity-federation) and [PRD §6.2](../../docs/prd.md#62-sso-provider-configuration) for the full spec.
