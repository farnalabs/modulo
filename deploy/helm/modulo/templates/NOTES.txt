=== Access ===

{{- if .Values.ingress.enabled }}
Ingress is enabled. Access Modulo at:
{{- range .Values.ingress.hosts }}
  https://{{ .host }}
{{- end }}
{{- else }}
Port-forward to access Modulo locally:

  # Frontend (port 80)
  kubectl port-forward svc/{{ include "modulo.fullname" . }}-frontend 8080:{{ .Values.frontend.service.port }} -n {{ include "modulo.namespace" . }}

  # Backend API (port 8000)
  kubectl port-forward svc/{{ include "modulo.fullname" . }}-backend 8000:{{ .Values.backend.service.port }} -n {{ include "modulo.namespace" . }}

Then open: http://localhost:8080
{{- end }}

=== Admin Access ===

Create an admin user by setting MODULO_USERS in the backend env:

  helm upgrade {{ .Release.Name }} ./deploy/helm/modulo \
    --set backend.env.MODULO_USERS="admin:$(openssl passwd -6 your-password)"

Or use existingSecret to reference a pre-created Kubernetes Secret.
